# Color UI V2

- Color panel redesigned to remove the conceptual duplication:
  - Source Color: Auto (unknown) / Normal / D-Log M (manual selection only; Unknown shown as Auto (unknown), never presented as a normal mode).
  - Color Restoration: None / DJI Osmo Action 4 D-Log M to Rec.709 (the technical transform into the working space).
  - Creative Look: Original / Forest Pro / Ice Pro / Nature Pro.
- The technical transform is visually and semantically separated from the source color decision.
- Labels are fully localized (English + Simplified Chinese) through the translation registry.
