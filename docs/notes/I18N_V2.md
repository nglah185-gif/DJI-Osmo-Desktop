# I18N V2

Supported languages are English (`en`, default) and Simplified Chinese (`zh-CN`). Runtime selection is persisted with `localStorage` key `dji-osmo-language`; unsupported keys fall back to English.

The lightweight registry lives in `src/i18n/`. Browser code exposes `window.i18n.t`, `getLanguage`, `setLanguage`, and `apply`. The initial pass covers the header, storage, media, preview, and language selector while preserving filenames, paths, codecs, and camera model strings.

Registry parity and non-empty coverage are tested in `test/i18n.test.js`. Existing Phase tests remain unchanged.

Known limitation: several legacy editor labels still need conversion to `data-i18n` keys for complete UI coverage.
